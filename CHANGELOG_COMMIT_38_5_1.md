# Commit 38.5.1 · Corrección de álbumes

- El formulario Nuevo álbum permite seleccionar varias fotografías directamente desde el PC.
- Se muestran miniaturas antes de guardar.
- Se puede pulsar una miniatura para elegirla como portada antes de crear el álbum.
- Al guardar se crea el álbum, se suben las fotografías y se asigna la portada seleccionada.
- Se mantienen las opciones Fotos y portada para añadir, eliminar o cambiar la portada después.
- Se añaden mensajes de error y progreso durante la subida.
- No requiere cambios SQL.
