COMMIT 32.0 - CATÁLOGO DE MATERIAL

CAMBIOS PRINCIPALES
- La antigua sección Material/Tienda se presenta como "Catálogo de Material".
- Se aclara que el material pertenece a la Peña Frente Comepipas.
- Se aclara que no existe venta ni pago online.
- El socio puede pulsar sobre toda la tarjeta del producto para solicitarlo.
- La solicitud se confirma posteriormente por WhatsApp o correo electrónico.
- Las fotografías usan object-fit: contain y ya no se recortan en ordenador.
- Se añade vista del producto dentro del formulario de solicitud.
- Se mejoran estados de disponibilidad y accesibilidad con teclado.
- Se actualiza el texto "Material" a "Catálogo" en los menús públicos.
- Se añaden versiones ?v=32.0 para evitar problemas de caché.

SUPABASE
No requiere ejecutar SQL ni modificar tablas.

PRUEBA RECOMENDADA
1. Publicar los archivos en GitHub/Vercel.
2. Recargar la web con Ctrl + F5.
3. Abrir tienda.html desde ordenador y móvil.
4. Comprobar que las fotografías se ven completas.
5. Pulsar tanto la imagen como el cuerpo de un producto.
6. Enviar una solicitud de prueba y comprobar su confirmación.
